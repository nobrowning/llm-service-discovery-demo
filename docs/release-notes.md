Demo 0.6.2 bundles the Mac-tested Harness plugin 0.5.2, fixes missing discovery-error details, and adds a complete macOS Desktop installation and troubleshooting guide. The native macOS/Linux/Windows deployment and Windows/Ubuntu WSL container deployment remain available.

- `llm-service-discovery-demo-0.6.2-native.zip`: installed JavaScript dependencies, plugin and common CLI, no Docker image. Requires Node.js 24+ for your architecture. Run `node scripts/verify-release-files.mjs`, list interfaces, then `node packages/lab-controller/cli.mjs native run --runtime .runtime/native --interface YOUR_LAN_IPV4`. See `docs/native-quickstart.md`.
- `llm-service-discovery-demo-0.6.2-windows-x64-wsl.zip`: the same sources/dependencies plus a prebuilt linux/amd64 image. Requires Windows x64, Node.js 24+, existing x64 Ubuntu WSL. Run `scripts/start-demo.ps1`; first-time Docker static/Compose downloads require internet. See `docs/windows-quickstart.md`.
- `SHA256SUMS`: verify the archive before extraction. Each ZIP also has a manifest and per-file checksums. Automatic Source code archives do not include installed dependencies or the image.

Native startup manages two API/advertiser children, waits for readiness, and withdraws announcements on stop. Status, stop and lifecycle tests use an authenticated loopback channel. Multiple interfaces require an explicit local IPv4; incomplete runtime directories are preserved and rejected. Private files are generated locally and retained across restarts.

Bundled components: core 0.3.1, advertiser 0.3.1 and Harness plugin 0.5.2. Discovery socket errors now retain a bounded diagnostic message in the authenticated plugin state and UI. This made the actual macOS Desktop local-network permission failure visible; allowing Harness in System Settings restored discovery. The package checksum regression also accepts prerelease filenames and compares the exact archive digest. CI checks Windows x64, Linux x64/arm64 and macOS x64/arm64 with architecture assertions.

Use the CLI bundled with your Harness Host. Compatibility remains 0.2.1-rc.3/rc.5. Follow `docs/mac-desktop-quickstart.md` for Mac setup, application-specific local-network permissions, profile paths and real conversation checks. Exact Desktop UI, isolated Host and server/network results are recorded separately in `docs/validation-report.md`; Mac results do not qualify Linux Web UI or Intel Mac hardware. The native ZIP is not a standalone app installer, and the WSL image is not multi-architecture. Runtime credentials and profiles are excluded.
